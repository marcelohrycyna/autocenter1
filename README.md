FrontEnd
Sistema criado para o gerenciamento de manutenções, fluxo de atendimento e histórico de veículos e clientes.
Este projeto foi criado com o objetivo de demonstrar e aprofundar meus conhecimentos práticos no framework Angular, aplicando conceitos de arquitetura frontend, consumo de APIs e gerenciamento de estado. 
Para dar suporte à aplicação, foi construído integrado com .NET e SQL.

Utilizando tecnologias:
  Frontend: Angular
  Backend: .NET (C#, Web API)
  Banco de Dados: SQL Server
